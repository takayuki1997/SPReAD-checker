# SPReAD 応募書類 形式チェック（ブラウザ版）

第2回 SPReAD 公募の形式チェックツール（文科省配布の `research_plan_self_check.py` /
`form_self_check.py`）を、**Python のインストール不要・ブラウザだけ**で使えるようにしたものです。

- 判定ロジックは配布版の `.py` を**そのまま**ブラウザ内で実行するため、結果は配布版と同一です。
- 書類は**利用者のPCの外に出ません**（ブラウザ内の Python(Pyodide/WASM) で処理）。
  通信は、最初に計算エンジン（Pyodide）と必要ライブラリを読み込むときだけ発生します。
- **アクセス解析・トラッキングは一切使用していません**（Google Analytics 等の外部送信なし・Cookie 不使用）。
- Windows / Mac 共通。配布物は単一HTMLファイル 1 つ。

## 対応する様式

公式 .py が対応している様式をそのまま扱えます。

- **様式1（研究計画調書・Excel）**：**日本語版・英語版の両方**に対応（`research_plan_self_check.py` が版を自動判定し、文字数／語数などの基準を版ごとに切り替え）。
- **様式0・2・3・4（PDF）**：申請様式チェックリスト／各種同意確認書。**学生が提出する確認書2種（様式3「学生応募の同意確認書」・様式4「指導教員等の同意確認書」）も対象**です（`form_self_check.py`）。

## 配布物

ビルドすると `docs/index.html`（自己完結の単一ファイル）が生成されます。これが配布物の正本で、GitHub Pages の公開元でもあります。

`index.html` を静的ホスティング（GitHub Pages など）に置き、URLを共有して使います。更新が一括で反映でき、`localStorage` も安定します。
※書類はPC外に出ません。初回起動時のみネット接続が必要です。

実ブラウザ(Chrome)で動作確認済み。

## 使い方（利用者）

1. 公開URLを開く。
2. **① ツールを読み込む**：公式から入手した `research_plan_self_check*.py` /
   `form_self_check*.py` をドラッグ＆ドロップ（ファイル名で種別を自動判別。`_v1` 等が付いていてもOK）。
3. **② 書類を読み込む**：様式1（.xlsx）や 様式0・2・3・4（.pdf）をドラッグ＆ドロップ（複数可）。
4. 「チェック実行」を押す。初回はエンジン読込で十数秒〜数十秒かかります。
5. 画面に「判定サマリー」「詳細チェック」が表示され、結果Excelもダウンロードできます。

## 開発・ビルド

```
# 依存（検証用）
python3 -m venv .venv && .venv/bin/pip install openpyxl pdfminer.six pypdf
npm install            # pyodide, puppeteer-core

# ビルド（既定: ツール同梱なし。利用者が .py を実行時に読み込む）
node web/build.mjs           # -> docs/index.html（約29KB・UIのみ）

# （任意）自機関内で同梱したい場合のみ。再配布に当たり得る点に留意。
node web/build.mjs --embed   # vendor/*.py を埋め込む（約148KB）
```

### 文科省がツールを改訂したら

- **同梱なし（既定）の場合**：HTMLはUIのみのため、原則**改修不要**。利用者が新しい `.py` を読み込めば追従できる。
  ライブラリ追加など仕様変更があればテンプレートを調整。
- **同梱版を使う場合**：新しい `.py` を `vendor/` に上書き →`node web/build.mjs --embed` 再実行 → 配布。

## 検証の記録

- 様式1（Excel）: ネイティブ実行と Pyodide 実行の判定結果が**全セル一致**（差分はファイルパス表示のみ）。
- 様式0/2/3/4（PDF）: pdfminer.six による抽出が Pyodide 上でも動作し、種別判定・判定結果がネイティブと一致。
- 英語版の様式1（Excel）／学生用の確認書（様式3・4 PDF）も、実ブラウザ経由で投入→判定→結果表示まで動作を確認（英語版は結果も英語項目で出力）。
- 実ブラウザ(Chrome): http配信 / file:// の両方で、投入→判定→表示→Excelダウンロードまで成功。

## ツール(.py)のキャッシュ

利便性のため、読み込んだ **.py（公式ツール）だけ** をブラウザに保存（`localStorage`）し、次回以降は読み込み不要にしています。

- **書類は一切キャッシュしません**（機密のため）。保存対象は公開ツールの .py のみ。
- **40日で自動失効**：保存時刻を記録し、40日を超えたら自動破棄して「最新版を読み込み直してください」と表示。公募中にツールが更新された場合の保険。
- 画面の「保存を消去」でいつでも手動削除可。失効日数は `index.template.html` の `TOOL_CACHE_MAX_DAYS` で変更可。
- 注意：`localStorage` は配信元（オリジン）ごと・端末/ブラウザのプロファイルごとに分離されます（端末やブラウザを変えると再読み込みが必要＝仕様）。
